# 🌐 Personal Portfolio Website

> ⚠️ Note: All personal/contact information displayed in this project is for educational/demo purposes only.

🔗 https://omkarpai2007.github.io/sqrock_myportfolio/

## ✨ Features

- 🎨 Modern Dark Theme UI  
- 🌌 Animated Particle Background using Canvas

## ⚙️ Setup Instructions

### Method 1: Clone Repository
```bash
git clone https://github.com/OmkarPai2007/sqrock_myportfolio.git
```

---

### Method 2: Download ZIP

1. Click the **Code** button on GitHub  
2. Select **Download ZIP**  
3. Extract the ZIP file  

---

### Run Locally in VS Code

1. Open the project folder in **Visual Studio Code**  
2. Install the **Live Server** extension (if not installed)  
3. Right-click on `index.html`  
4. Click **"Open with Live Server"**  

Your portfolio will open in the browser at:

```bash
http://127.0.0.1:5500/
```
