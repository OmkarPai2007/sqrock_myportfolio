# 🌐 Personal Portfolio Website

A modern responsive portfolio website built using **HTML, CSS, and JavaScript** to showcase my profile, skills, and projects with an interactive animated UI.

> ⚠️ Note: All personal/contact information displayed in this project is for educational/demo purposes only.

---

## 🚀 Live Demo
🔗 https://omkarpai2007.github.io/sqrock_myportfolio/

---

## ✨ Features

- 🎨 Modern Dark Theme UI  
- 🌌 Animated Particle Background using Canvas  
- 📱 Responsive Design for Mobile/Desktop  
- 🧑‍💻 Hero Section with Floating Profile Image  
- 🙋 About Me Section  
- 🛠 Skills Showcase Cards  
- 📂 Project Cards Section  
- ⚡ Smooth Scroll Navigation  
- ✨ Hover Effects & Animations  
- 🔗 Social Media Footer Icons  

---

## 🛠 Tech Stack

- HTML5  
- CSS3  
- JavaScript  
- Font Awesome Icons  
- HTML Canvas API
